# Проверки и решения

2026-10-05. Среда: macOS 27.2 ARM64, Docker Desktop, Linux aarch64.
Контейнер собран: Ubuntu 22.04.5, Humble, Fortress 6.18.0, Nav2 1.1.20.
Чистый colcon build: один пакет, успешная сборка. Тесты: 13 пройдены в ROS-среде.

Первый запуск выявил конфликт атрибута Node.handle; используется goal_handle.
Nav2 ждём через lifecycle GetState(active), одного обнаружения action недостаточно.
URDF конвертер переименовывает collisions; validate_model.py проверяет ссылки
контактных сенсоров по реальному SDF. Контактные топики Fortress имеют полные пути.

Живое облако Fortress использует x вперёд, y влево, z вверх. Для PointCloud2
назначен camera_link; optical frame оставлен для изображения. TF base_footprint
лежит на земле, base_link на высоте 0.2 м. Это исправляет высоты obstacle layer.

Probe-04: первая цель достигнута, низкое препятствие попадало в costmap,
но робот задел его углом. Причина: BaseObstacle проверяет стоимость центра;
выбран ObstacleFootprint для ориентации прямоугольного корпуса. Этот запуск
не считается успешным и не входит в демонстрацию.

Каждый интеграционный прогон запускается в свежем контейнере: это исключает
остаточные ROS/DDS-участники предыдущего запуска.

Probe-05: достигнута Б, но контактный сенсор подтвердил касание низкого
препятствия. В общей 2D obstacle layer лучи лидара очищали отметки depth.
Для лидара и depth выбраны независимые слои: ObstacleLayer и VoxelLayer.
Воксели сохраняют высоту препятствия, объединение слоёв выполняется по максимуму.

Probe-06: служба смены lifecycle-состояния потеряла ответ в Fast DDS.
Выбран поддерживаемый Humble Cyclone DDS; повторные прогоны создают новый
контейнер вместо перезапуска контейнера с прежними DDS-ресурсами.

Тайм-ауты и watchdog переведены на steady clock: остановка /clock не должна
останавливать отмену цели и контроль устаревших данных. Контакт блокирует
привод и завершает маршрут ошибкой. Проверка startup timeout использует
use_sim_time=true без /clock. Тесты: 16 пройдены.

Контрольный run-01-final: A → Б, 43.407 с wall time, ground-truth ошибка
0.157283 м, минимальное SAT-разделение 0.441478 м, 0 контактов и пересечений.
Видео 74.867 с и rosbag 235.6 MiB. TF: 11 рёбер, по одному DDS GID на ребро.

Команда scripts/run.sh выявила несовместимость shell nounset с ROS setup;
исправлено. Run-02-final через scripts/run.sh: 46.603 с, ошибка 0.150958 м,
минимальное SAT-разделение 0.464278 м, 0 контактов. Все критерии check_run зелёные.

Результат независимого ревью и регрессии: docs/review.md. 24 теста пройдены.
Replay с исключённым /clock и перенаправленным TF RSP подтвердил одного
издателя времени и все 11 рёбер TF без дубликатов.

Недостижимая цель: ABORTED за 22.303 с при тайм-ауте 35 с,
привод остановлен, контактов нет. Доказательства: docs/evidence/unreachable.
Дополнительная регрессия сохраняет failure report после закрытия ROS-контекста;
полная серия: 25 тестов пройдены.

Финальная Docker-сборка сравнила полный manifest с lock без расхождений.
Дополнительный запуск с GUI через scripts/run.sh выявил задержку TF и контакт
с центральным блоком. Прогон final-smoke неуспешен; диагностика продолжается.
Видео полностью декодировано ffmpeg без ошибок.

Повтор GUI с записью после перехода local costmap в map также неуспешен:
planner продолжал начинать путь в А при движущемся роботе. Возраст latest TF
не проверяется автоматически timeout-параметром lookup. Добавлена сверка
stamp и центра published_footprint local costmap со свежим независимым TF.

Контроль Fast DDS через UDP без SHM воспроизвёл старую позу local costmap.
Новый watchdog завершил миссию за 3.739 с до движения и контакта:
0 команд на приводе, 0 контактов/пересечений. Короткие доказательства:
docs/evidence/controller-stale. Замена RMW сама по себе проблему не устранила;
основной стек остаётся Cyclone DDS.

Поток physics/clock/joint_states/contacts снижен с 500 до 100 Гц (шаг 0.01 с).
GPS, lidar, depth и odometry сохраняют заданные частоты. Это уменьшение
нагрузки, а не доказательство конкретного дефекта DDS. Первый контрольный GUI
с новой конфигурацией: 47.106 с, ошибка 0.135494 м, SAT 0.455990 м, контактов нет.

Параллельная чистая сборка C++-сборщика во время rate-video дала краткую
задержку TF около Б. Контактов нет, ошибка позиции 0.181758 м, но миссия
корректно завершилась failure; этот прогон не засчитывается как успех.
COLCON_IGNORE исключил независимый helper из основной colcon-сборки:
чистая сборка теперь один пакет, 0.89 с, без предупреждений.
Для миссии добавлено ожидание восстановления TF до 2 wall секунд;
watchdog продолжает закрывать привод немедленно при устаревании.

Финальный release-run: 41.908 с, ошибка 0.171887 м, SAT 0.442004 м, 0 контактов.
Повтор release-repeat: 47.303 с, ошибка 0.099526 м, SAT 0.460165 м, 0 контактов.
В обоих прогонах все 12 критериев check_run прошли. Видео 83.334 с,
rosbag 237.4 MiB, окончательный replay TF/clock проверен.
Недостижимая цель: ABORTED за 21.404 с; привод нулевой, контактов нет.
