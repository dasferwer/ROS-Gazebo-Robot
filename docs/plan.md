# Реализация и проверка

1. Поднять контейнер со стеком и виртуальным дисплеем; сохранить версии.
2. Написать тесты WGS84 → ENU → map и ограниченного автомата маршрута.
3. Реализовать модель, сенсоры, контактную проверку, мир и статическую карту.
4. Настроить мост, TF, AMCL, Nav2 и Python-исполнитель GPS-waypoints.
5. Запустить чистую сборку и интеграцию; исправить выявленные проблемы.
6. Снять два проезда, проверить недостижимую цель, сохранить отчёты и rosbag.
7. Записать 1–3 минуты Gazebo + RViz; оформить README и ответы по электронике.
8. Проверить локальный Git-репозиторий без публикации.

Особое внимание: оптическая система depth-камеры, направление осей GPS,
дубликаты TF, остановка на устаревших данных, тайм-ауты действий.
