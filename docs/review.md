# Итоговое ревью

Независимый read-only reviewer GPT-6 Astra проверил архитектуру, собственный
код, конфигурацию, README и доказательства первого проезда. Критических
замечаний нет. Три существенных замечания исправлены:

1. При тайм-ауте future принятия цели мог уже завершиться, хотя goal_handle
   ещё не был сохранён. Теперь отменяется и завершённый future, и принятая
   позднее цель. Два случая покрыты регрессией RED → GREEN.
2. Replay исключает записанный `/clock`; TF publisher описания робота
   перенаправлен в отдельные топики. Живой replay подтвердил одного
   издателя `/clock` и одного издателя каждого из 11 рёбер TF.
3. Проверка TF теперь требует полный набор рёбер, одного родителя каждого
   child и одного издателя времени. Регрессии отвергают пустой/неполный
   отчёт, второго родителя, второго издателя TF и второго издателя `/clock`.

Также уточнены прямые зависимости package.xml и отдельно задан optical
frame для изображения depth. Облако остаётся в camera_link. Скрипт запуска
не включает nounset до чтения ROS setup: setup обращается к необязательным
переменным окружения.

Дополнительное ревью неудачного GUI-прогона выявило в Nav2 1.1.20
игнорирование результата transformPose в ControllerServer::isGoalReached.
Устаревшее преобразование цели поэтому не гарантировало прекращение команд.
Local costmap и behavior collision checker согласованы в map. В собственные узлы
добавлен контроль возраста и продвижения TF, физический timestep сохранён.
Ревью указало, что отдельный свежий Python TF-buffer сам по себе не доказывает
свежесть буфера controller; поэтому проверки TF дополняют выбор общей frame.
Повторная диагностика уточнила: timeout lookup не проверяет возраст latest TF.
Добавлена независимая проверка stamp и центра published_footprint local costmap;
устойчивый отказ защёлкивает привод и отменяет миссию. Регрессия проверяет
расхождение поз даже при свежем TF и невозможность снять защёлку статусом running.
Исходник: https://github.com/ros-navigation/navigation2/blob/1.1.20/nav2_controller/src/controller_server.cpp

Полная серия модульных проверок после исправлений: 28 тестов, без пропусков.
Фактические результаты интеграции приведены в verification.md.
